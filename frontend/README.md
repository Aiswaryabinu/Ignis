# Ignis Frontend

This frontend scaffold follows the requested module layout for the Ignis product platform.

## Structure

- `src/app` contains app wiring, router, and providers.
- `src/components` contains shared UI and layout primitives.
- `src/features` contains business features grouped by domain.
- `src/lib` holds shared API, formatting, roles, and constants.
- `src/styles` includes design tokens and global styling.

## Getting started

```bash
npm install
npm run dev
```
